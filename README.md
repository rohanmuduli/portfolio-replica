# Portfolio Replica 💼

A sleek, modern, and responsive personal portfolio website featuring interactive typing effects, floating animations, project showcases, and a dynamic tech stack display.

🔗 Live Demo: https://portfolio-replica-website.netlify.app/
📁 GitHub Repository: https://github.com/rohanmuduli/portfolio-replica.git

---

## ✨ Features

- 🎭 Dynamic Role Typing: Interactive typewriter effect powered by Typed.js cycling smoothly through developer specializations.
- ⚡ Interactive Floating Animations: Engaging geometric micro-animations (cubes, circles, dots, zigzags) in the hero section.
- 💼 Featured Projects Showcase: Project cards complete with numbered badges, tech stack icons, project descriptions, and direct links.
- 🛠️ Visual Tech Stack: Comprehensive display of frontend, backend, devops, and database skill icons on an organic vector background.
- 📩 Interactive Contact Form: Dedicated contact section with responsive input fields and stylized action buttons.
- 📱 Responsive Layout: Clean layout designed to adjust smoothly across desktop, tablet, and mobile devices.
- 🚀 Pure & Lightweight: Built using clean HTML5, CSS3, and minimal JavaScript without heavy external framework overhead.

---

## 🛠️ Tech Stack

- HTML5: Semantic structure using custom layout containers, forms, and sectioning elements.
- CSS3: Advanced CSS positioning, Flexbox, keyframe animations, custom gradients, transitions, and hover effects.
- JavaScript: Interactive dynamic typewriter animations powered by Typed.js.
- Icons & Fonts: Font Awesome 6 icons and Google Web Fonts.

---

## 🚀 Getting Started Locally

To run this project locally on your machine:

1. Clone the repository:

   ```bash
   git clone https://github.com/rohanmuduli/portfolio-replica.git
   ```

2. Navigate into the project directory:

   ```bash
   cd portfolio-replica
   ```

3. Open the application:

   - Double-click `index.html` or open it with your browser of choice.
